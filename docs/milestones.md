# Milestones
## Milestone 0: Modelización del problema
El objetivo es modelizar el problema, para ello, a partir de [HU001] se plantean issues que enuncian los subproblemas del dominio. Esos issues guían la aplicación de domain driven design que dará como resultado fragmentos de código que modelizan el problema.

Será valido si se ha aplicado la metodología correctamente, los issues representan los subproblemas de la HU, cada fragmento de código se ha generado en un issue, se han seguido las buenas prácticas en los commits y el código obtenido representa el dominio del problema.

## Milestone 1: Implementación de la lógica de negocio
Se crearan nuevos issues con los problemas de lógica de negocio de [HU001]. Estos nuevos issues permitirán añadir funcionalidad al modelo obtenido durante el Milestone 0. Se obtendrán nuevos fragmentos de código que implementan la lógica.

Será válido si los tests se ejecutan automáticamente y se superan, verificando que en el código obtenido se está aplicando correctamente la lógica de negocio implementada.
