# Milestones
## Milestone 0: Modelización del problema
El objetivo es modelizar el problema, para ello, a partir de [HU001] se aplicará la metodología domain driven design que dará como resultado un modelado válido del problema mediante código.

Será válido si se ha aplicado la metodología correctamente y se han aplicado las buenas prácticas tanto en los commits como en la generación del código mediante issues.
## Milestone 1: Implementación de la lógica de negocio
Se aplicará una nueva metodología, Test Driven Development, sobre [HU001]. La aplicación de esta metodología permitirá añadir funcionalidad al modelo obtenido durante el Milestone 0.

Será válido si los tests verifican que se ha resuelto el problema, si al ejecutarse automáticamente se superan y si se han mantenido las buenas prácticas.
