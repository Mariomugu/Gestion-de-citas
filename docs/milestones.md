# Milestones
## Milestone 0: Modelización del problema
El objetivo es modelizar el problema de Eva, para ello, a partir de [HU001] se plantean issues que enuncian los problemas del dominio. Esos issues guían la aplicación de domain driven design como metodología que dará lugar a la modelización completa del mismo mediante código.

Será valido si tras finalizar la aplicación de DDD, esta se ha aplicado correctamente y el código obtenido representa de forma correcta y completa el dominio del problema.

## Milestone 1: Implementación de la lógica de negocio
Se crearan nuevos issues con los problemas de lógica de negocio de [HU001]. Estos nuevos issues permitirán añadir funcionalidad al modelo obtenido durante el Milestone 0

Será válido si los tests se ejecutan automáticamente y se superan, verificando que en el código obtenido se está aplicando correctamente la lógica de negocio implementada.
